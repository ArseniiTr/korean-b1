# Корейский до B1 — интерактивный учебник

Личный адаптивный учебник корейского (A1 → B1 / TOPIK 3 / 3급 по шкале 한국어학당).
Сайт статический (`index.html`, один файл), прогресс и упражнения — через воркер `korean-b1-tutor` на Cloudflare Workers (бесплатный тариф, не засыпает)
(вход по коду доступа, ключ Anthropic хранится только на сервере, модель Haiku 5.5 с выключенным размышлением — самый экономичный вариант).

Сайт: https://arseniitr.github.io/korean-b1/

## Что внутри
- **Тренировка**: 7–8 заданий за серию — грамматика (выбор, подстановка, исправление, сборка предложения), чтение короткого текста, письмо (перевод, свободное письмо, диалог). Все сюжеты про бытовую жизнь в Корее: 14 сцен (편의점, 지하철, 카페, 시장, 병원·약국, 한강 …) с плоскими векторными иллюстрациями.
- **Разбор ошибки**: при неверном ответе коротко и понятно по-русски объясняется, в чём именно ошибка (слово, частица, окончание).
- **Дословный перевод** («Дословно»): перевод по словам в корейском порядке с пометками частиц — помогает понять структуру предложения.
- **Темы**: программа по Integrated Korean Beginning 1–2 и «Korean Language for Beginners» Де Бенедиттиса, стартовая точка — по конспекту ученика. У каждой темы явный статус **«не начата» → «учу» → «сдана»** и видимые критерии сдачи с прогрессом (см. ниже); на странице тем — сводка «сдано / учу / впереди», какие темы пойдут в следующую тренировку и какая новая тема следующая.
- **Чем дополнить учебник**: подборка проверенных бесплатных источников для иностранцев по ярусам 1급–3급 (한국어기초사전 с русским интерфейсом, Naver 사전, Nuri-Sejong Hakdang, Talk To Me In Korean, How to Study Korean, курс Ёнсе на Coursera, Korean Grammar in Use, Billy Go, koreanverb.app, Anki, TOPIK) — внизу страницы «Темы», а в каждом уроке — ссылки для его яруса и поиск разбора конструкции в HTSK/TTMIK.
- **Слова**: 734 слова по уровням 1급 / 2급 / 3급, карточки с интервальным повторением, быстрая проверка «знаю / не знаю», список с отметками. Цель — знать 80 % словаря каждого уровня. **Умная калибровка**: если в задании ученик ошибся на слове, отмеченном «знаю», оно переходит в «учу» — перестаёт считаться знакомым (и выпадает из расчёта уровня), идёт в карточках первым и возвращается в знакомые после трёх «Помню» подряд или галочки в списке.
- **Ачивки**: бытовые ситуации в Корее («Кафе и ресторан», «Рынок»). Каждая — советы, как себя вести и что принято, нужные фразы и мини-тест из 10 заданий (6 локальных про фразы и их смысл, 4 от ИИ под уровень: диалоги и переводы). Значок — при 8 верных из 10. Советы по-русски до 3급, с 3급 переписываются по-корейски под уровень ученика.

## Статусы тем и критерии сдачи
Статус считается только из данных прогресса (`state.topics[id] = {s, n, c, t, r, p}`: освоение, ответов, верных, время, история последних 10 ответов, верных «своими словами»), вручную не ставится.
- **Не начата** — ответов нет и темы нет в конспекте.
- **Учу** — есть ответы или тема помечена знакомой по конспекту (стартовая точка, освоение 0,6). Если точность последних ответов ниже 50 % — «учу · повторить», такая тема идёт в тренировку первой.
- **Сдана** — выполнены все критерии: (1) точность ≥ 80 % из последних 10 ответов, не меньше 6 ответов; (2) ≥ 3 верных ответа «своими словами» — перевод, письмо, диалог, исправление ошибки, сборка предложения; (3) все слова словаря из примеров темы отмечены знакомыми (их можно подтвердить чипами прямо в уроке). Слова темы находятся сопоставлением примеров со словарём по леммам (отсечение частиц, основа глагола с учётом чередований ㅂ/ㄷ/ㄹ/르/ㅅ/ㅎ).

Задания генерируются только по темам в статусе «учу»: самая слабая из начатых плюс следующая новая (пока начатых тем меньше трёх) или вторая слабая. Старый формат прогресса мигрирует автоматически: история восстанавливается из счётчиков пропорционально точности, счётчик «своими словами» начинается с нуля.

## Умная калибровка словаря
При неверном ответе ИИ, кроме разбора ошибки, возвращает `words` — словарные формы слов, которых ученик не знал или перепутал (до 3, без частиц и окончаний; это те же запросы `check`, лишних вызовов нет). Слова сопоставляются с лемма-списком словаря; найденные «знаю»-слова получают `k:false`, счётчик ошибок `x` и дату `xt`, выпадают из подсчёта знакомого словаря и из `tierVocab` при расчёте уровня и встают в начало очереди карточек. В словаре такие слова видны с чипом «учу» и отдельным фильтром. Работает в тренировке, чтении, письме и тестах ачивок; калибровочный тест по-прежнему помечает слова напрямую.

## Методика оценки уровня
Шкала — Институт корейского языка Университета Ёнсе (연세대학교 한국어학당): 6 уровней 급, учебник ведёт до 3급 ≈ TOPIK 3 ≈ B1 («общение, достаточное для повседневной жизни»). Объёмы словаря по уровням — по государственному стандарту 국제 통용 한국어 표준 교육과정 (1급 ≈ 735 слов, 2급 ≈ 1100, 3급 ≈ 1655).

Уровень — непрерывное число 0…3,5, из которого берутся параметры генерации (словарный ярус, длина предложений, длина текста для чтения):
1. **Грамматика яруса**: среднее по темам уровня min(1, освоение / 0,8). Освоение — сглаженная точность ответов; статус «сдана» на уровень напрямую не влияет, но сданные темы имеют освоение ≈ 0,8–1.
2. **Словарь яруса**: доля знакомых слов уровня относительно цели 80 %; слова, вернувшиеся в «учу» после ошибок, знакомыми не считаются.
3. **Балл яруса** = 0,5 · грамматика + 0,5 · словарь; ярус считается пройденным при ≥ 0,7, иначе уровень = (ярус − 1) + доля.
4. **Недавняя точность** (последние 20 ответов по навыку): > 85 % → +0,2, < 55 % → −0,3.
5. **Калибровка** (аналог 반편성시험: 12 слов по ярусам, 6 вопросов по грамматике, чтение, письмо; говорение без звука не оценивается). Результат весит 0,6 и затухает за ~120 ответов.
6. **Самооценка** — кнопки «Мне сложно / Мне легко» (±0,25, максимум ±1, затухает на 20 % за тренировку); автоматически −0,25 при точности серии < 40 % и +0,25 при > 90 %. Влияет только на сложность генерации, не на оценку уровня.
7. Навыки (грамматика / чтение / письмо) считаются отдельно; самый слабый получает дополнительное задание в каждой серии.

## Структура
- `index.html` — сайт целиком (стили, иллюстрации, программа, словарь, ачивки, логика).
- `worker/` — серверная часть на Cloudflare Workers + D1: вход по PIN, прогресс, журнал ответов, прокси к Anthropic. Команды деплоя и схема — в `worker/README.md`.
- `supabase/functions/tutor/index.ts` — прежняя версия сервера (Supabase Edge Function), больше не используется.

## Где живут данные
Всё хранится в базе Cloudflare D1 `korean-b1` (SQLite), доступной только воркеру:
- `app_config` — хеш кода доступа и ключ Anthropic;
- `sessions` — токены входа (180 дней);
- `progress` — прогресс ученика (одна JSON-запись);
- `attempts` — журнал ответов по темам;
- `ai_calls` — учёт вызовов модели и токенов.

Данные из Supabase перенесены в D1 1 ноября 2026; с этого дня сайт ходит на `https://korean-b1-tutor.korean-b1-tutor.workers.dev`.
